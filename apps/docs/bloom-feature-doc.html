Overview

What Bloom does

Bloom serves two distinct audiences who each have their own interface within a single mobile app. Guardians (caregivers, parents, support workers) create and manage learner profiles, assign AI-generated tutorials, schedule activities, and connect with other guardians. Learners (IDD individuals) experience a simplified, accessible interface to learn from tutorials, chat with friends, complete daily activities, and express their mood.

A third interface — the Admin Portal (web app) — lets platform administrators moderate AI-generated tutorials, manage categories and situation tags, and monitor platform usage.

Guardian Guardian

Full management interface: creates learner accounts, generates and assigns tutorials, sets daily activities, manages schedule, and builds connections with other caregivers.

Learner Learner

Simplified, AAC-friendly interface optimised for accessibility: biometric login, mood check-in, friends & chat with a symbol board, tutorial playback, and activity checklist.

Admin Admin

Web portal for tutorial moderation, category and situation tag management, user oversight, and platform statistics.

AI Engine

Guardian-triggered tutorial generation via Supabase Edge Functions. Produces slideshow frames with AI images, captions, narration text, and synthesised audio. 10 tutorials/month per guardian.

Login

The app always opens to the Guardian Login screen — there is no auto-redirect based on prior state. Guardians enter email and password. A "Forgot password?" link navigates to the Forgot Password page, which sends a Supabase recovery email. The recovery link opens a dedicated Reset Password page.

Home & Dashboard Guardian

Learner Select Screen

When a guardian has one or more learners, the first screen shown after login is the Learner Select screen. It displays a guardian card (photo, full name, email) and learner tiles below it. Tapping the guardian card navigates to Guardian Home. Tapping a learner tile triggers biometric authentication (Face ID / Touch ID) to switch into that learner's session. If a guardian has no learners yet, this screen is skipped and they go directly to Guardian Home.

Guardian Home

The central dashboard organises access to all guardian features. It shows:

  • For You — six action tiles: Tutorials (with unreviewed count badge), Activities (preset count badge), Schedule, Connections, Discussions, Events
  • Your Learners — horizontal scroll of learner avatars with name and assigned tutorial count; plus an "Add New" tile
  • Community — "Find Friends" (learner discovery) and "Friend Requests" tiles

The guardian's avatar appears in the header and opens an account dropdown (Account, Sign Out). A back button appears when learners exist, returning to the Learner Select screen.

Tutorials Guardian

My Tutorials (Guardian view)

Lists all tutorials created by this guardian with a status filter bar: All / Review Needed / Pending / Approved / Rejected. Each card shows thumbnail, title, category, format, comprehension level, status badge, and a monthly quota pill.

Create Tutorial

A 3-section accordion form for AI-powered tutorial generation:

What to Teach

Target skill (chip grid), core action (text, max 60 chars), display name for learner, format (slideshow / video), duration.

Look & Feel

Visual style, image style, pacing (Slow / Normal), tone (Calm / Enthusiastic).

Context

Comprehension level, language, background audio.

Quota

10 tutorials per guardian per month. Remaining credits shown as a pill on the form.

On submit, a Supabase Edge Function generates frames with AI images, captions, narration text, and audio. The tutorial is created in "generating" status and polled every 4 seconds until frames are ready.

Preview & Edit

The guardian reviews each frame: image, caption, narration text, audio playback. They can edit any frame's image prompt (triggering AI regeneration), caption, and narration text. When satisfied, they submit for admin review. If rejected by admin, they can revise and resubmit.

Tutorial Library

A searchable grid of all admin-approved tutorials from all guardians. Filter by skill, comprehension level, and format. Guardians can assign any tutorial to their learners and mark up to 3 per learner as "Favourites" (surfaced prominently in the learner's Tutorials screen).

Activities Guardian

Setup

A preset-based activity system. The guardian selects up to 7 daily activities from a preset grid (e.g., Brush Teeth, Morning Stretches, Read a Book). Selected presets automatically appear in every learner's daily checklist. Saved via an RPC call; changes take effect the next day.

Report

A 7-day completion report per learner. Each day shows emoji pips for each activity (coloured = done, dimmed = not done), a mini progress bar, and a fraction count. Gives guardians a quick view of consistency over the past week.

Schedule Guardian

Weekly Recurring Classes

The guardian picks a learner, then sets recurring class templates per day of the week. Each template has: title, emoji (with keyword-based suggestions), start and end time (30-min intervals, 6 AM–9 PM), and valid-from / valid-until dates. Classes appear as tiles on the learner's home screen when they are happening (or imminent).

One-off Events

The guardian can add a one-time class on a specific date, or cancel a recurring class on a specific date without removing the template.

Learner Experience

On the learner's Home screen, today's next scheduled class appears as a prominent tile with a countdown ("In 45 mins") or a pulsing "Now" badge. Local push notifications are scheduled each time the learner's home screen gains focus.

Community Guardian

Connections

A guardian-to-guardian networking screen. Shows all other guardians with their name, their learner's details, comprehension level badge, and situation tags. Filterable by location, tags, learner age, and comprehension level. Guardians can send, accept, or decline connection requests.

Learner Discovery

Guardians browse other learners (not in their own care) and initiate friendship requests on behalf of their learners. Filters for age range, comprehension level, and name/city search. Tapping a learner opens their public profile. Accepting a learner friendship also auto-creates a guardian-to-guardian connection.

Friend Requests

All pending learner friendship requests (incoming and outgoing) managed in one place. Guardians accept or decline incoming requests; can cancel outgoing ones.

Discussions

A guardian-only community forum. Guardians create posts (title + body) and reply to threads. Posts show author, timestamp, and reply count.

Events

Guardians create and RSVP to community events. Each event has a name, description, date, time, and venue. Three RSVP states: Going / Interested / Not Going. Event cards show a date-tag widget and going count.

Notifications

A notifications inbox for friend requests, messages, and profile changes. Unread count badge. Friend request notifications have inline Accept / Reject buttons. All notifications mark as read on tap.

Account Settings Guardian

The guardian can edit: profile photo (image picker → Supabase Storage), full name, phone number, location (city + state), and situation tags. Each field section has a view mode and an inline edit mode with Save / Cancel. Changes are reflected immediately in the app via a context refresh.

Learner

Home Learner

The learner home screen is designed for accessibility and clarity. It shows a personalised greeting, a large mood emoji badge (tappable to open a mood picker), and a grid of four feature tiles: Friends, Messages, My Mood, and Learn.

Two contextual tiles appear at the top of the grid when relevant:

  • Schedule tile — shows the next class with title, emoji, time, and a countdown or pulsing "Now" badge. Only shown when a class is scheduled today.
  • Activities tile — shows "X of Y done" with a progress bar. Only shown when activities have been set by the guardian.

Mood Check-in

The learner taps the mood badge to open a four-option mood picker: Happy, Sad, Angry, Tired. Each mood has a large emoji. Long-pressing any mood speaks its name aloud. The selected mood is saved to the learner's profile and displayed as a badge on their avatar throughout the app.

Friends & Messages Learner

Friends Hub

Shows the learner's accepted friends in three sections: Favourites (pinned), Online Now, and All Friends. Each card shows the friend's avatar with a mood badge, an online status dot (green if seen within 5 minutes), name, and interest emojis. A speaker button reads out the friend's name and interests aloud. Tapping a friend opens a 1:1 chat.

Friend Discovery

Controlled by guardians — learners cannot send friend requests themselves. A guardian-managed screen (Learner Discovery) handles all connection initiation on the learner's behalf.

1:1 Chat

A real-time chat screen with a custom header (friend's photo, online status, speaker button). Features include:

  • Text messaging with speech-to-text support
  • Read-aloud for any received message (speaker button per bubble)
  • AAC Communication Board — a grid of 80+ downloadable symbol images (cached after first load). Tapping a symbol speaks it aloud and sends the image as a message
  • Realtime delivery via Supabase Postgres Changes subscription

Learning Learner

Tutorials Screen

Shows tutorials assigned by the guardian, grouped by category. A "⭐ Your Favourites" section at the top features up to 3 guardian-starred tutorials. A category filter dropdown lets the learner browse by skill area.

Slideshow Player

Each tutorial frame shows an AI-generated image, caption, and narration text. Playback options:

  • Auto-play — advances frames automatically using stored audio (if available) or device TTS; a 3-second timer advances if neither is available
  • Manual browse — Previous / Next buttons and dot position indicators
  • TTS narration reads the frame text aloud with a "reading" indicator
  • A "Done ✓" button appears on the last frame

Video Player

Full-screen dark player using native video controls for video-format tutorials (admin-uploaded content).

Activities Learner

A daily checklist set by the guardian. A progress card at the top shows today's date, "X of Y done", and a green progress bar. When all activities are complete, a "🌟 Amazing job today!" banner is shown. Each activity card displays a large emoji, the activity name, and a circular checkbox. Tapping an item toggles completion — completed items move to the bottom.

Profile Learner

The learner's public-facing profile: avatar with mood badge, name, age, gender, location, languages; chip sections for Likes, Dislikes, and What I Can Do; chat preferences (available for chat/Zoom/voice, available days, comprehension level); and health information (only shown if the learner has consented to share). Editing opens the guardian-managed Edit Profile flow.

Admin Portal

Admin Portal Admin

A React web app (Vite) with its own Supabase auth. Only users in the admins table can access it.

PageWhat it does
Dashboard 4 stat cards: Guardians, User Profiles, Tutorials, Pending Connections
Tutorials — Library Grid of all approved tutorials. Click to preview frame-by-frame.
Tutorials — Moderation FIFO queue of pending tutorials. Admin reviews each frame, then Approves or Rejects with optional notes that appear in the guardian's preview screen.
Tutorials — Upload Admin can manually upload video tutorial files with title, description, and category, bypassing AI generation.
Users Searchable table of all learner profiles: name, age, gender, city, guardian info, join date.
Categories Add / delete interest categories (Like, Dislike, Ability types) used in learner profiles.
Situation Tags Add / delete situation tag options that appear in guardian registration and account settings.

Auth flows

Login page includes a "Forgot password?" link to the Forgot Password page. The recovery email links back to the admin portal and shows a dedicated Reset Password form (detected via the PASSWORD_RECOVERY event from Supabase Auth — the admin is not logged into the dashboard until they set a new password).
